# gpt-image-2 尺寸与质量参考

## 常用尺寸

| size | 用途 |
|------|------|
| `1024x1024` | 方形（最快） |
| `1536x1024` | 横向 |
| `1024x1536` | 纵向 |
| `2048x2048` | 2K 方形 |
| `2048x1152` | 2K 横向 |
| `3840x2160` | 4K 横向 |
| `2160x3840` | 4K 纵向 |
| `auto` | 默认，由模型决定 |

## 尺寸约束

- 最长边 ≤ 3840px
- 两边都是 16 的倍数
- 长短边比 ≤ 3:1
- 总像素 ∈ [655,360, 8,294,400]

## 质量

`low` / `medium` / `high` / `auto`（默认 auto）

## 模型

默认 `gpt-image-2`。脚本兼容 OpenAI 风格 `/v1/images/generations` 接口，也可传 `--model dall-e-3` 等其它模型。

## 返回

OpenAI 兼容格式：

```json
{
  "created": 1700000000,
  "data": [
    { "url": "https://..." }   // 或 { "b64_json": "..." }
  ]
}
```

脚本会自动下载 url 或解码 b64_json，保存到 `--output-dir`。
